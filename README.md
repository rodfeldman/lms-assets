# lms-assets

Banners de capa gerados por IA para posts da comunidade LMS — Academia Lendária.

Este repositório existe apenas para hospedar publicamente imagens de capa (via GitHub Pages),
usadas como `cover_url` em posts do calendário editorial.

## Regras

- Somente imagens genéricas geradas por IA. Nada de dados de membros, PII ou conteúdo interno.
- Nenhum arquivo de configuração, segredo ou código de outros projetos.

## Estrutura

```
images/AAAA-MM-DD-slug.png
```

URL pública: `https://rodfeldman.github.io/lms-assets/images/<arquivo>`
